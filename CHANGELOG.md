# Что изменилось в версии 1.0.0

## Исправлено
- **Показывались только 500 из 669 слов** (`prefix(500)`): слова от «pull» до «young» не появлялись никогда. Теперь доступны все.
- Слова шли по алфавиту → теперь фиксированное перемешивание (seed) по всему словарю + колоды по темам.
- Слово «прыгало» после отметки → текущая карточка закреплена в плане виджета, следующая берётся из очереди.
- Выученные слова не возвращались → интервальные повторения (Лейтнер).
- `id` = английское слово (коллизии омонимов) → стабильные id (`b:…` / `c:UUID`), прогресс хранится отдельно.
- Удалённые встроенные слова возвращались при обновлении словаря → список удалённых (`deletedIDs`).
- JSON декодировался на каждую из 49 записей таймлайна → библиотека читается один раз; хранение в файле App Group (с резервной копией).
- Деструктивные кнопки без подтверждения → `confirmationDialog`.
- Данные из виджета не обновлялись в открытом приложении → обновление при `scenePhase == .active`.
- Круглый виджет → кольцо цели дня + слово в центре.
- Кнопки виджета работают без разблокировки (`authenticationPolicy = .alwaysAllowed`) — проверьте на устройстве.
- Все строки вынесены в `Localizable.xcstrings` (ru / en / uk).
- Версия виджета берётся из `MARKETING_VERSION`; добавлены иконка, Privacy Manifest, Info.plist, `ITSAppUsesNonExemptEncryption`.

## Добавлено
- Виджет-тренировка: «глаз» → «Знал / Не знал»; настройка колоды и режима для каждого виджета; домашний экран, StandBy; тап по виджету открывает карточку.
- Приложение: экран «Сегодня» (цель, серия, неделя, прогресс), карточки со свайпом, тест, ввод слова, озвучка (US/UK), транскрипция и примеры, колоды по темам, детали слова.
- Добавление слов: проверка дубликатов, автоперевод (Apple Translation, iOS 18), импорт/экспорт CSV (Anki), Share Extension.
- Онбординг с анимацией, напоминания (на 7 дней вперёд, пропускаются если уже занимались), iCloud-синхронизация прогресса и своих слов,
  кнопка в Пункте управления (iOS 18), Siri/Shortcuts.

## Известные ограничения
- Уровни A1–C1: в модели есть темы, но слов только уровня Pre-Intermediate. Для уровней нужен новый словарь.
- Переводы встроенных слов только на русский.
- Синхронизация — iCloud Key-Value Store (до 1 МБ): прогресс и свои слова, но не настройки.
- Напоминание не отменяется, если за день занимались только в виджете, пока вы не откроете приложение.
- Apple Watch не реализован.
