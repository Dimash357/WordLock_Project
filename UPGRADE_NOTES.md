# WordLock — обновление

## Изменения
- Timeline виджета теперь планирует смену слова с интервалом 15/30/60/120/240 минут (фактическое время контролирует iOS).
- Кнопка на прямоугольном виджете отмечает именно показанное слово, а не устаревший `currentWord`.
- Статистика изученных слов, ручная отметка и отмена отметки, сброс прогресса.
- Поиск по английскому слову и переводу.
- Защита от повторного добавления одинаковых английских слов.
- Настройка частоты обновления виджета.
- Сохранены существующие ключи App Group и UserDefaults; данные должны сохраниться при обновлении поверх существующего приложения с тем же Bundle ID и Team.

## Установка на iPhone
1. На Mac распакуйте архив и откройте `WordLock/WordLock.xcodeproj` в Xcode.
2. В `Signing & Capabilities` выберите свою Apple Developer Team для приложения и Widget Extension.
3. Для обновления поверх старого приложения оставьте те же Bundle IDs и App Group, что и в старой установленной сборке. В текущем проекте: `com.katsuro.WordLock`, `com.katsuro.WordLock.Widget`, `group.com.dimash.wordlock`.
4. Подключите iPhone к Mac, подтвердите доверие, при необходимости включите Developer Mode.
5. Выберите iPhone в Xcode и нажмите Run (⌘R). Не удаляйте старую версию, если хотите сохранить слова.
6. На экране блокировки удерживайте палец → Настроить → Добавить виджеты → WordLock.

## Ограничения
- Код изменён без запуска Xcode: необходима проверка сборки на Mac.
- Виджеты обновляются по расписанию приблизительно, без гарантии точного интервала.
- Если изменена подпись/Team/App Group относительно установленной версии, данные могут не перенестись.
