# WordLock

Простое приложение для iPhone, которое показывает английские слова и перевод
в виджете на экране блокировки.

## Что уже реализовано

- 500 слов уровня Pre-Intermediate;
- добавление своих слов;
- удаление слов;
- общий список для приложения и виджета через App Group;
- кнопка-галочка: отмечает слово как выученное и сразу показывает следующее;
- выученные слова не повторяются, пока не будет пройден весь список;
- прямоугольный, круглый и однострочный Lock Screen Widget.

## Как открыть проект на Mac

Проект подготовлен для генератора XcodeGen. На Mac выполните:

```bash
brew install xcodegen
cd WordLock
xcodegen generate
open WordLock.xcodeproj
```

В Xcode:

1. Выберите target `WordLock`, затем Signing & Capabilities.
2. Выберите свою Team и замените Bundle Identifier `com.example.WordLock` на
   уникальный, например `com.yourname.WordLock`.
3. Повторите для `WordLockWidgetExtension`.
4. Создайте одинаковую App Group для обоих targets.
5. Замените `group.com.example.WordLock` в двух `.entitlements` файлах и в
   `Shared/WordItem.swift` на идентификатор своей App Group.
6. Выберите iPhone или симулятор и нажмите Run.

После установки удерживайте экран блокировки, нажмите «Настроить», выберите
область виджетов и добавьте WordLock.

## Важно

iOS сама управляет точным временем обновления виджетов. Проект создаёт записи
на следующие 24 часа с интервалом в один час, но система может показать их с
небольшой задержкой.
