# WordLock

Карточки с английскими словами на экране блокировки iPhone. Виджет работает как мини-тренировка:
смотришь слово → нажимаешь «глаз» → видишь перевод → отвечаешь «Знал» / «Не знал».
Слова повторяются по системе интервальных повторений (Лейтнер, коробки 1/3/7/14/30 дней).

## Сборка
Требуется **Xcode 16+**, iOS 17+ (автоперевод и Пункт управления включаются на iOS 18+).

```bash
brew install xcodegen
xcodegen generate        # создаст WordLock.xcodeproj (старый .xcodeproj можно удалить)
open WordLock.xcodeproj
```

1. В `project.yml` раскомментируйте `DEVELOPMENT_TEAM` и впишите свой Team ID (или выберите команду в Xcode для трёх целей).
2. Capabilities: у приложения и обоих расширений должна быть **App Groups** `group.com.dimash.wordlock`;
   iCloud-синхронизация по умолчанию выключена (не работает с бесплатным Personal Team), см. `WordLock/iCloud.entitlements.txt`.
   Если вы меняете Bundle ID или группу — замените `AppGroup.id` в `Shared/Models.swift` и три `.entitlements`.
3. Запустите схему `WordLock` на устройстве (виджеты на экране блокировки лучше проверять на реальном iPhone).

## Структура
| Папка | Что внутри |
|---|---|
| `Shared/` | Модели, хранилище (JSON в App Group), SRS, планировщик виджета, интенты, словарь, `Localizable.xcstrings` |
| `WordLock/` | Приложение: экран «Сегодня», тренировки, словарь, настройки, онбординг, iCloud, напоминания, Siri |
| `WordLockWidget/` | Виджет (экран блокировки, домашний экран, StandBy) и кнопка Пункта управления |
| `ShareExtension/` | «Поделиться → WordLock»: добавить слово из Safari и других приложений |

Словарь: `Shared/Vocabulary.swift`, строка `слово|перевод|транскрипция|тема|пример`. Идентификатор встроенного слова — `b:<слово>`,
поэтому при обновлении словаря прогресс пользователей не теряется.

## Язык
Исходный язык интерфейса — русский, переводы en и uk лежат в `Shared/Localizable.xcstrings`.
Переводы встроенных слов пока только на русский; для своих слов автоперевод поддерживает другие языки.
